# 个人网站微信小程序

这是一个原生微信小程序单页个人主页，入口为 `pages/index/index`。

## 在微信开发者工具中预览

1. 打开微信开发者工具，选择「小程序」→「导入项目」。
2. 项目目录选择本文件夹。
3. AppID 可选择「测试号」或填写你自己的小程序 AppID。
4. 编译后点击右上角「预览」，使用微信扫描开发者工具生成的二维码。

## 上线前需要替换

- `pages/index/index.wxml` 中的姓名、简介、邮箱和版权年份。
- `pages/index/index.js` 中的作品卡片、经历时间线。
- 如果需要头像，可把 `avatar-placeholder` 替换成 `<image>` 并加入本地图片。
