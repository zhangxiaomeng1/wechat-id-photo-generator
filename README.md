# WeChat ID Photo Generator

一个原生微信小程序，底部包含两个标签：证件照工具和陪伴宇宙。

- **证件照**：上传照片并导出一寸、二寸白底证件照。
- **陪伴宇宙**：通过实时摄像头或相册创建本地分身，选择陪伴角色、情绪和互动动作。

当前版本在本地完成图片裁剪、尺寸排版、JPG 导出和分身卡片展示，不会上传原图。

## 在微信开发者工具中预览

1. 打开微信开发者工具，选择“小程序”→“导入项目”。
2. 项目目录选择本仓库。
3. 填写你自己的小程序 AppID，或使用测试号。
4. 编译后点击右上角“预览”，使用微信扫描开发者工具生成的二维码。

## 元宇宙页面说明

第二个“陪伴宇宙”标签是本地优先的 2D 分身体验：

- 通过微信相机拍摄，或从相册选择头像照片。
- 使用本地文件保存分身路径和互动状态。
- 选择“星芽”“潮汐”“轨道”三个陪伴角色。
- 切换平静、专注、好奇三种状态，并进行招呼、漫游、呼吸互动。

当前未接入远程 AI 图像生成或 3D/VRM 服务；如果接入，需要另外完成用户授权、隐私政策、模型服务和数据删除流程。

## 上线前需要替换

- 当前导出为白底证件照；蓝底/红底需要后续接入抠图能力。
- 如需接入云端图像处理服务，请先补充隐私政策、用户授权和数据删除流程。
