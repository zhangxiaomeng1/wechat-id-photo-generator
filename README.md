# WeChat ID Photo Generator

一个原生微信小程序证件照生成器，支持上传照片并导出一寸、二寸白底证件照。

当前版本在本地完成图片裁剪、尺寸排版和 JPG 导出，不会上传原图。

## 在微信开发者工具中预览

1. 打开微信开发者工具，选择“小程序”→“导入项目”。
2. 项目目录选择本仓库。
3. 填写你自己的小程序 AppID，或使用测试号。
4. 编译后点击右上角“预览”，使用微信扫描开发者工具生成的二维码。

## 上线前需要替换

- 当前导出为白底证件照；蓝底/红底需要后续接入抠图能力。
- 如需接入云端图像处理服务，请先补充隐私政策、用户授权和数据删除流程。
